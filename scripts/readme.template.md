# {{brand.name}} ({{brand.name_ar}})

A dark satellite globe for finding an empty parking space and driving to it. It starts in Dubai and London and is built to widen to the whole globe. English and Arabic (RTL), mobile-first. Generated from `brand.json`; do not edit this file by hand.

## Run

```
npm install
npm run dev        # http://localhost:5173 (API proxy mounted)
npm run build      # type check, brand check, production build into dist/
npm run serve      # serve dist/ with the API proxy and security headers (port 8787)
npm test           # unit tests
```

Server settings are read from environment variables starting with `{{brand.env}}` (see `.env.example`): `_HOST`, `_PORT`, `_ALLOWED_HOSTS`, `_RATE_PER_MIN`, `_ROUTER_URL`. No secret keys are used or needed.

## How the parking flow works

1. **My location** asks the browser for your position. If that is refused, tap the map to say where you are. Your position stays in the browser: it is never written to share links and is only sent to the route service as coordinates when you ask for a route.
2. **Find free spot** picks the nearest lot in your city with free spaces and draws the drive to it along real roads. A lot's card also has **Route from my location**.
3. Free spaces are **simulated** (see below). `occupancyAt` in `src/data/parking-sample.ts` is the one function to replace with a real feed, such as an operator API, sensors or camera counts.

## Data and honesty notes

- Imagery: Esri World Imagery (keyless, subject to Esri terms; OpenStreetMap tiles are the fallback). Flights: adsb.lol (ODbL) through `/api/flights`; military aircraft are excluded. Roads and routing: OpenStreetMap data through the public OSRM demo server (`/api/route`), which is for light use only. Set `{{brand.env}}_ROUTER_URL` to your own router for real traffic.
- If no road router answers, the app draws a dashed straight line and says so. If live flights never load, DEMO aircraft are shown and labelled.
- Parking lots, capacities and occupancy, metro/tram/bus, and property activity are illustrative SAMPLE data. Lot positions are approximate points near well-known places.
- Landmark, district and station coordinates are approximate. Verify before relying on them.
- Skipped by design: CCTV, plate readers, military sites, fire perimeters.

## Map stack (same idea as gods-eye-view)

- **Default, no keys:** Esri World Imagery satellite plus keyless 3D terrain relief (Mapterhorn data via Re:Earth, CC BY 4.0). OpenStreetMap tiles take over if Esri is unreachable.
- **Photorealistic 3D buildings (optional):** set `{{brand.env}}_CESIUM_ION_TOKEN` on the server to a Cesium ion token (eligible personal or non-commercial use, limited to your site and read-only assets). The server hands it to the page at runtime, a **3D buildings** switch appears in Display, and the globe switches to Google Photorealistic 3D Tiles. Without a token you get the flat satellite stack above, which is what gods-eye-view also does without keys.

## Globe notes

The map is CesiumJS (Apache-2.0). `npm run dev` and `npm run build` copy Cesium's runtime files into `public/cesium`; that folder is generated.
